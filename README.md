# zed-mpls

Zed extension for [Markdown Preview Language Server](https://github.com/mhersson/mpls).

https://github.com/user-attachments/assets/669bc099-aa68-4b89-ba84-32618ddb60c4

# Usage

1. `git clone https://github.com/pnyda/zed-mpls.git`
2. Open Zed command palette
3. Choose `zed: install dev extension`
4. Choose `extension.toml` in the repo
